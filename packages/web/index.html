A HARDWARE-KEY NOTEBOOK

Private notes.
Physical key.

Unlock your notebook with a USB security key. Write in your browser and save a single encrypted file wherever you choose.

Open Secure Notes ↗ How it works ↓

Requires a USB FIDO2 key with WebAuthn PRF support.

THE WORKFLOW

From key to encrypted file

  1. 01

    Unlock

    Register your USB security key to create a vault. A second key can serve as a backup.

  2. 02

    Write

    Edit plain-text notes in the browser. The app encrypts your notes with AES-256-GCM before saving.

  3. 03

    Save

    Keep the encrypted vault as one .snote file. Open it again with a registered key on the same hostname.
